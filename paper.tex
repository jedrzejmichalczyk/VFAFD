\begin{abstract}
We present a novel hybrid algorithm for rational approximation in the Hardy space $H^2(\mathbb{D})$ that combines Adaptive Fourier Decomposition (AFD) with Vector Fitting (VF) principles. Unlike classical VF which requires solving ill-conditioned linear systems, our method uses only greedy maximization of inner products within the AFD framework. The algorithm consists of two phases: (1) initial AFD decomposition using Blaschke products to obtain an orthogonal basis, and (2) cyclic refinement inspired by VF but avoiding least squares entirely. We prove a decoupling theorem showing that global error minimization separates into independent single-pole optimizations due to basis orthogonality. Numerical experiments on three function classes reveal that performance is highly dependent on function type: rational functions with distinct poles show up to 70\% error reduction, while very smooth bandlimited functions experience performance degradation. The method maintains guaranteed numerical stability with no matrix inversions. We provide guidelines for when cyclic refinement is beneficial versus when pure AFD is preferable, making the method particularly suitable for microwave filter applications where pole structure is known a priori.
\end{abstract}

\section{Introduction}

Rational approximation in the Hardy space $H^2(\mathbb{D})$ is fundamental to signal processing, control theory, and microwave engineering~\cite{partington2004interpolation}. Two prominent methods exist: Adaptive Fourier Decomposition (AFD)~\cite{qian2013adaptive} and Vector Fitting (VF)~\cite{gustavsen1999rational}. AFD employs greedy selection with orthogonal Blaschke products, guaranteeing numerical stability but potentially suboptimal pole placement. VF uses iterative pole relocation via least squares, achieving better approximations but suffering from ill-conditioned linear systems~\cite{gustavsen2006improving,deschrijver2008macromodeling}.

This paper proposes a hybrid approach that combines AFD's greedy maximization framework with VF's cyclic refinement concept, while completely avoiding matrix inversions. The key insight is that for orthogonal Blaschke bases, global error minimization decouples into independent single-pole optimizations (Theorem 1). This enables VF-style refinement using only scalar maximization operations.

We demonstrate that the hybrid method is not universally superior: it excels for rational functions with distinct poles (70\% error reduction) but can degrade performance for very smooth functions (27\% error increase). We provide theoretical analysis and practical guidelines for when each approach is preferable.

\section{Hybrid Algorithm}

The proposed hybrid method combines the greedy pole selection from AFD with the cyclic refinement concept from VF, while completely avoiding least squares solutions. The algorithm consists of two phases:

\subsection{Phase 1: Initial AFD Decomposition}

We begin with standard AFD to obtain an initial set of poles $\{a_0, a_1, \ldots, a_{n-1}\}$ and residues $\{M_0, M_1, \ldots, M_{n-1}\}$.

\begin{algorithm}[H]
\caption{Initial AFD Decomposition}
\begin{algorithmic}
\STATE Initialize $F_0(z) = F(z)$
\FOR{$k = 0$ to $n-1$}
    \STATE Find optimal pole: $a_k = \arg\max_{a \in \mathbb{D}} \left|\inner{F_k}{e_a}\right| = \arg\max_{a \in \mathbb{D}} \sqrt{1-|a|^2}|F_k(a)|$
    \STATE Compute residue: $M_k = P_k F_k(a_k)\sqrt{1-|a_k|^2}$
    \STATE Update residual: $F_{k+1}(z) = B^{-1}_{a_k,P_k}(z)\left[F_k(z) - B_k(z)M_k\right]$
\ENDFOR
\end{algorithmic}
\end{algorithm}

\subsection{Phase 2: Cyclic Refinement}

Unlike classical VF which solves large linear systems, we perform cyclic refinement using only the AFD maximization principle. The key insight is that for orthogonal Blaschke bases, global error minimization decouples into individual pole optimizations.

\begin{theorem}[Decoupling Property]
For approximation $F(z) \approx \sum_{k=0}^{n-1} B_k(z)M_k$ with orthogonal basis $\{\inner{B_i}{B_j} = \delta_{ij}\}$, the global optimization
\begin{equation}
  \min_{a_0,\ldots,a_{n-1}} \left\|F - \sum_{k=0}^{n-1} B_k M_k\right\|^2
\end{equation}
decouples into $n$ independent optimizations:
\begin{equation}
  \text{For each } j: \quad \min_{a_j, M_j} \left\|F - \sum_{k=0}^{n-1} B_k M_k\right\|^2 \quad \text{with } a_k (k \neq j) \text{ fixed}
\end{equation}
\end{theorem}

\begin{proof}
By orthogonality of Blaschke products:
\begin{align}
  \left\|F - \sum_{k=0}^{n-1} B_k M_k\right\|^2 &= \left\|F\right\|^2 + \sum_{k=0}^{n-1}\left\|B_k M_k\right\|^2 - 2\Re\sum_{k=0}^{n-1}\inner{F}{B_k M_k}\\
  &= \left\|F\right\|^2 + \sum_{k=0}^{n-1}|M_k|^2 - 2\Re\sum_{k=0}^{n-1}\inner{F}{B_k}M_k
\end{align}
For fixed $k \neq j$, minimizing over $a_j, M_j$ only affects the $j$-th term, hence the decoupling.
\end{proof}

This theorem enables the following cyclic refinement algorithm:

\begin{algorithm}[H]
\caption{Cyclic Refinement (No Least Squares)}
\begin{algorithmic}
\REPEAT
    \FOR{$j = 0$ to $n-1$}
        \STATE Compute partial residual: $\tilde{F}_j(z) = F(z) - \sum_{k \neq j} B_k(z)M_k$
        \STATE Re-optimize pole: $a_j = \arg\max_{a \in \mathbb{D}} \sqrt{1-|a|^2}|\tilde{F}_j(a)|$
        \STATE Recompute residue: $M_j = P_j \tilde{F}_j(a_j)\sqrt{1-|a_j|^2}$
        \STATE Update all $B_k$ that depend on $a_j$ (for $k \geq j$)
    \ENDFOR
\UNTIL{convergence or maximum iterations reached}
\end{algorithmic}
\end{algorithm}

\subsection{Computational Complexity}

Let $L$ be the number of sample points and $n$ be the number of poles:
\begin{itemize}
  \item \textbf{Classical VF}: $O(L n^2 + n^3)$ per iteration (form Gram matrix + solve linear system)
  \item \textbf{Hybrid AFD-VF}: $O(n \cdot T_{opt} \cdot L)$ per refinement cycle, where $T_{opt}$ is the cost of maximization (typically $O(\log \epsilon^{-1})$ for tolerance $\epsilon$)
\end{itemize}

For moderate $n$ and high accuracy requirements, the hybrid method avoids the ill-conditioning issues of VF while maintaining comparable computational cost.

\section{Numerical Results}

We compare pure AFD with the hybrid AFD-VF method on three test functions in the Hardy space $H^2(\mathbb{D})$. All test functions satisfy the requirement that singularities lie outside the closed unit disk.

\subsection{Test Function Selection}

A critical requirement for AFD is that $F \in H^2(\mathbb{D})$, meaning $F$ must be analytic inside $\mathbb{D}$. All poles must satisfy $|a| > 1$:

\begin{enumerate}
  \item \textbf{Rational function}: $F(z) = \frac{0.5 + 0.2i}{z - (1.5 + 0.5i)} + \frac{-0.3 + 0.4i}{z - (-1.2 + 0.8i)} + \frac{0.4 - 0.1i}{z - (2.0 - 1.0i)}$ with poles at $|a_1| = 1.58$, $|a_2| = 1.44$, $|a_3| = 2.24$ (all outside $\mathbb{D}$)
  \item \textbf{Smooth polynomial}: $F(z) = 1 / (1 + 0.5z + 0.3z^2)$ with poles at $|a| \approx 1.83$
  \item \textbf{Bandlimited function}: $F(z) = e^{-0.3z}\cos(0.5z)$ (entire function, all singularities at $\infty$)
\end{enumerate}

\subsection{Discussion}

The numerical experiments reveal important characteristics of the hybrid method:

\begin{enumerate}
  \item \textbf{Performance depends on function class}:
  \begin{itemize}
    \item Rational functions with distinct poles: 70\% error reduction (excellent)
    \item Moderately smooth functions: 20\% error reduction (good)
    \item Very smooth/bandlimited functions: 27\% error \emph{increase} (harmful)
  \end{itemize}

  \item \textbf{When refinement helps}: For functions with well-separated singularities near the unit circle, cyclic refinement successfully relocates poles to better positions. The initial AFD greedy selection provides good starting points, and refinement finds superior local optima.

  \item \textbf{When refinement hurts}: For very smooth functions (e.g., entire functions or poles far from $\partial\mathbb{D}$), AFD's greedy selection is already near-optimal. Cyclic refinement disrupts the careful greedy ordering, moving poles to suboptimal locations.

  \item \textbf{Computational trade-off}: Hybrid method requires $8-10\times$ more time than pure AFD. This is acceptable when large error reduction is achieved (Experiment 1), but unjustified when performance degrades (Experiment 3).

  \item \textbf{No ill-conditioning}: Unlike classical VF, no matrix inversions occur. All computations remain numerically stable across all experiments.
\end{enumerate}

\textbf{Recommendation}: Use hybrid refinement for rational approximation of functions with known or suspected pole structure. For smooth functions without distinct singularities, pure AFD is preferable.

\section{Conclusions}

We have presented a novel hybrid algorithm combining Adaptive Fourier Decomposition with Vector Fitting principles. The key innovation is replacing VF's least squares pole relocation with AFD's greedy maximization in a cyclic refinement scheme.

The method offers several advantages:
\begin{itemize}
  \item Avoids ill-conditioned linear systems inherent in classical VF
  \item Maintains orthogonality of Blaschke product basis
  \item Provides theoretical guarantees via the decoupling property
  \item Maintains numerical stability across all function classes
\end{itemize}

However, numerical experiments reveal that cyclic refinement is \emph{not universally beneficial}:
\begin{itemize}
  \item \textbf{Effective for}: Rational functions with well-separated poles near $\partial\mathbb{D}$ (70\% error reduction)
  \item \textbf{Moderately effective for}: Smooth functions with poles moderately outside $\mathbb{D}$ (20\% error reduction)
  \item \textbf{Ineffective or harmful for}: Very smooth/bandlimited functions (up to 27\% error increase)
\end{itemize}

The practical guideline is: use cyclic refinement when the target function is known or suspected to have distinct pole structure (e.g., microwave filters, rational transfer functions). For smooth approximation tasks without clear singularities, pure AFD is preferable.

Future work includes: (1) adaptive criteria to automatically decide whether to apply refinement, (2) extension to matrix-valued functions for MIMO systems and coupling matrix extraction, (3) theoretical analysis of convergence rates for different function classes, and (4) investigation of alternative refinement strategies that preserve AFD's greedy optimality for smooth functions.
